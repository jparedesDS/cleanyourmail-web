# Brand explorations

Three banner directions were rendered for the October 2026 website update. They share the same
envelope mark, lime accent and type system.

| File | Direction | Use |
|---|---|---|
| `banner-a-editorial.png` | Dark editorial, headline + inbox card | Chosen for the website and this repository. |
| `banner-b-light.png` | Light “paper” variant | Alternate for print or light contexts. |
| `banner-c-terminal.png` | Terminal-first, commands + proof points | Used by the skill repository. |
| `social-editorial.png` | 1280×640 social preview for the editorial direction | Website Open Graph source. |
| `social-terminal.png` | 1280×640 social preview for the terminal direction | Skill repository social preview. |

The final site assets are `../banner.png` (1600×480) and `../og.png` (1280×640). The source renderer
was a local Pillow script; the site itself has no build step and no image dependency.
