# Provider logos

These marks identify the mail providers that CleanYourMail supports. They are trademarks of their
respective owners and do not imply endorsement.

All files are local PNGs with transparent backgrounds where the source allows it. The site loads
them directly; there are no third-party requests at runtime.

| File | Provider | Source |
|---|---|---|
| `gmail.png` | Gmail | Wikimedia Commons, [File:Gmail icon (2026).svg](https://commons.wikimedia.org/wiki/File:Gmail_icon_(2026).svg), rendered to PNG |
| `outlook.png` | Microsoft Outlook | Wikimedia Commons, [File:Microsoft Outlook Icon (2025–present).svg](https://commons.wikimedia.org/wiki/File:Microsoft_Outlook_Icon_(2025%E2%80%93present).svg), rendered to PNG |
| `yahoo.png` | Yahoo Mail | Wikimedia Commons, [File:Yahoo! Mail icon (2013-2019).png](https://commons.wikimedia.org/wiki/File:Yahoo!_Mail_icon_(2013-2019).png) |
| `icloud.png` | iCloud | Wikimedia Commons, [File:ICloud logo.svg](https://commons.wikimedia.org/wiki/File:ICloud_logo.svg), rendered to PNG |
| `fastmail.png` | Fastmail | Official Fastmail site header mark, extracted 2026-11-02 |
| `proton.png` | Proton Mail | Wikimedia Commons, [File:ProtonMail icon.svg](https://commons.wikimedia.org/wiki/File:ProtonMail_icon.svg), rendered to PNG |

The PNGs were trimmed to their visible artwork so they sit consistently on the dark cards without a
white backing chip.
