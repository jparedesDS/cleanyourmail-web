CleanYourMail is an open-source skill and CLI for IMAP cleanup. It reads headers only, files newsletters, promotions and spam, and shows you a plan before anything changes. Protected mail stays put. Unsubscribe is separate and irreversible.

Providers

Check your provider before you start.

No mailbox migration. You need IMAP access and the authentication method your provider allows.

  • GmailApp Password, 2FA and IMAP
  • Outlook / Microsoft 365OAuth2 access token; no token acquisition or refresh
  • YahooApp password
  • iCloud2FA and app-specific password
  • FastmailScoped app password; optional Sieve export
  • ProtonProton Mail Bridge running locally
  • Custom IMAPUIDPLUS or MOVE; resolvable Trash, Junk and Archive

Provider and tenant policies can block access. The CLI refuses unsafe or unsupported moves. See provider notes and validation status.

How it works

Nothing changes until you approve a plan.

  1. 01

    Connect locally

    Open the repo in your agent or terminal. Keep the credential in CYM_PASSWORD or a local password_file. doctor checks access and server capabilities.

  2. 02

    Scan and review

    scan reads header metadata only. report and plan let you review categories, protected mail, destinations and unsubscribe targets. None of them changes your mailbox.

  3. 03

    Move a small batch

    After you approve the plan, start with a few moves. The journal records the run and undo restores it. Review the result before handling unsubscribe separately.

Safety

Review first. Undo the moves.

Why local?

There is no hosted CleanYourMail service. The CLI runs on your machine, connects directly to your provider, and keeps the plan and undo journal in local files.

  • Hosted cleanerTypically: account, cloud dashboard, broader message access.
  • CleanYourMailLocal, no account, headers only, plan and journal on your machine.

No permanent deletion

There is no permanent-delete command. CleanYourMail never empties Trash or Junk and never runs a mailbox-wide expunge.

Headers only

It reads sender, subject, date, size, flags and unsubscribe headers, and stores that metadata locally. It never downloads bodies or attachments.

Protected mail stays put

Personal, transactional, security, banking, invoice, travel, medical, government, legal, starred, answered and recent mail is excluded from automatic moves and unsubscribe requests.

Review, move, undo

scan, report and plan change nothing. Review the plan, start with a small move, and use the journal and undo to restore that run. Unsubscribe is separate and irreversible.

FAQ

Questions before you connect.

Does it delete email?

No. It has no permanent-delete command, never empties Trash or Junk, and never runs a mailbox-wide expunge. Moves and archives are journaled; unsubscribe requests are not reversible.

What does it read?

Headers only: sender, subject, date, size, flags and unsubscribe headers. It never downloads bodies or attachments. The local cache stores metadata, not message bodies.

Do I need to be technical?

You do not need to write code, but setup requires Python 3.11+, a terminal and provider credentials. A coding agent can run the commands and explain the plan. You still review and approve any changes.

Does it work with my provider?

Gmail, Outlook/Microsoft 365, Yahoo, iCloud, Fastmail, Proton Bridge and compatible custom IMAP servers. Requirements vary: Microsoft needs an OAuth2 access token, Proton needs Bridge, and custom IMAP moves require UIDPLUS or MOVE. Provider or tenant policies may block access; the tool does not bypass them. Check the provider notes and validation status.

What happens if something goes wrong?

Stop and inspect the error. The CLI re-checks the plan before applying it and records each run. Use the printed undo command to restore that run’s moves. If a message cannot be found, the journal remains available for manual recovery. Unsubscribe requests cannot be undone.

Is it really free?

Yes. MIT-licensed, no paid tier, no CleanYourMail account and no telemetry. You provide your computer, Python installation and mail-provider access.

Will unsubscribe stop every sender?

No. Unsubscribe is a request, not a guarantee; some senders ignore it or take time to process it. CleanYourMail never unsubscribes from spam and uses unsubscribe headers rather than links in message bodies. Requests are irreversible.
