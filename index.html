How it works

Three steps. You stay in control.

  1. 01

    Connect

    Clone the repo, run init, put an app password or OAuth token in CYM_PASSWORD or a local password_file, then run doctor.

  2. 02

    Review

    scan reads headers only and report shows what it found. plan writes a reviewable plan.json; protected mail stays out.

  3. 03

    Clean

    apply moves a small batch. journal shows the run and undo restores it. Unsubscribe is separate and irreversible.

The CLI

One small command set.

Python 3.11+. No packages. Every command is explicit and reviewable.

doctor

Log in, check capabilities and find Trash, Junk and Archive.

scan

Cache headers and classify mail. No bodies, no attachments.

report

Summarize senders, categories and unsubscribe targets.

plan

Write plan.json with exact UIDs and destinations.

apply

Move a reviewed batch. Use --limit for the first run.

journal

Show runs, moved UIDs and the undo command.

undo

Restore a run after verifying Message-ID or X-GM-MSGID.

unsubscribe

Send opt-outs separately. Test last, with --limit 1.

folders

List or create mail folders.

unsubs

Show unsubscribe history.

rules

Export Gmail XML or a Sieve script for review.

Safety

Safe by design. Boring on purpose.

No permanent deletion

Moves copy first and use UID EXPUNGE. No mailbox-wide expunge. Trash is never emptied.

Headers only

The scan reads sender, subject, date, flags and unsubscribe headers. Bodies and attachments never leave the server.

Protected mail stays put

Banks, invoices, travel, medical, government, personal, starred, answered and recent mail are never auto-moved.

Undo every move

The journal records COPYUID and Message-ID. One command restores a run. Unsubscribe is the only irreversible step.

If the server has neither UIDPLUS nor MOVE, moves are refused. Read the safety rules ↗

FAQ

Short answers.

Does it delete email?

No. It moves mail to folders, labels, Junk, Trash or archive. It never empties Trash, never runs a mailbox-wide expunge, and has no “delete forever” command.

Does it read my email?

No. It reads headers only: sender, subject, date, size, flags and unsubscribe headers. Bodies and attachments are never downloaded.

Do I need to be technical?

You need Python 3.11+ and a terminal. A coding agent can run the CLI for you: paste PROMPT.md and follow the plan. The CLI is also usable directly.

Does it work with my provider?

Gmail, Outlook/Microsoft 365, Yahoo, iCloud, Fastmail, Proton Bridge and any IMAP server with UIDPLUS or MOVE. Outlook needs an OAuth2 access token; the CLI does not refresh it.

What is the first run?

Use scan --days 90, review the report, then plan. Apply at most five moves with --limit 5, check journal, and run undo before trying unsubscribe.
