작동 방식

계획을 승인하기 전까지는 아무것도 바뀌지 않습니다.

  1. 01

    로컬에서 연결

    에이전트에서 스킬을 열거나 앱을 사용하세요. 메일 서비스를 선택하고 자격 증명을 입력하세요. 무엇보다 먼저 연결을 테스트합니다.

  2. 02

    스캔하고 검토

    스킬이나 앱은 헤더 메타데이터만 읽습니다: 보낸 사람, 제목, 날짜, 크기, 플래그. 분류, 보호 메일, 대상 폴더, 구독 취소 대상을 보여 줍니다. 아직 아무것도 바뀌지 않습니다.

  3. 03

    작은 묶음으로 이동

    몇 개의 이동만 적용하세요. 저널이 실행을 기록하고 실행 취소가 이를 복원합니다. 구독 취소를 따로 처리하기 전에 결과를 검토하세요.

메일 서비스

쓰는 메일 서비스에서 그대로 작동합니다.

이전할 필요가 없습니다. IMAP 액세스와 해당 서비스가 허용하는 인증 방식만 있으면 됩니다.

  • Gmail앱 비밀번호 + 2단계 인증
  • Outlook / Microsoft 365Microsoft 365: 관리자 동의
  • Yahoo앱 비밀번호
  • iCloud앱 전용 비밀번호
  • Fastmail앱 비밀번호 + Sieve
  • ProtonProton Bridge

UIDPLUS 또는 MOVE를 지원하고 Trash, Junk, Archive를 확인할 수 있는 IMAP 서버라면 무엇이든 작동합니다. 메일 서비스별 참고 사항 · 검증 상태.

메일 서비스 이름과 로고는 각 소유자의 상표입니다.

안전성

먼저 검토하세요. 이동은 되돌리세요.

영구 삭제 없음

영구 삭제 명령은 없습니다. CleanYourMail은 Trash나 Junk를 비우지 않으며, 사서함 전체 expunge도 실행하지 않습니다.

헤더만

보낸 사람, 제목, 날짜, 크기, 플래그, 구독 취소 헤더만 읽고 그 메타데이터를 로컬에 저장합니다. 본문이나 첨부 파일은 절대 내려받지 않습니다.

보호 메일은 그대로

개인, 거래성, 보안, 은행, 청구서, 여행, 의료, 정부, 법무, 별표 표시, 답장 완료, 최근 메일은 자동 이동과 구독 취소 요청에서 제외됩니다.

검토, 이동, 되돌리기

scan, report, plan은 아무것도 바꾸지 않습니다. 계획을 검토하고 작은 이동부터 시작한 뒤 저널과 undo로 해당 실행을 복원하세요. 구독 취소는 별도이며 되돌릴 수 없습니다.

로컬에서 실행됩니다. 호스팅되는 CleanYourMail 서비스도, 계정도, 텔레메트리도 없습니다. 코드, 안전 모델, 테스트를 직접 확인하세요.

FAQ

연결하기 전에 궁금한 점.

메일을 삭제하나요?

아니요. 영구 삭제 명령이 없고, Trash나 Junk를 비우지 않으며, 사서함 전체 expunge도 실행하지 않습니다. 이동과 보관은 저널에 기록되지만 구독 취소 요청은 되돌릴 수 없습니다.

무엇을 읽나요?

헤더만 읽습니다: 보낸 사람, 제목, 날짜, 크기, 플래그, 구독 취소 헤더. 본문이나 첨부 파일은 절대 내려받지 않습니다. 로컬 캐시에는 메시지 본문이 아니라 메타데이터가 저장됩니다.

기술 지식이 필요한가요?

앱이 간편한 경로입니다. 주요 제품인 스킬은 셸 접근 권한이 있는 코딩 에이전트가 필요합니다. CLI는 터미널을 선호하는 개발자를 위한 것입니다. 세 가지 모두 같은 계획과 되돌리기 모델을 사용합니다.

내 메일 서비스에서도 작동하나요?

Gmail, Outlook/Microsoft 365, Yahoo, iCloud, Fastmail, Proton Bridge 및 호환되는 사용자 지정 IMAP 서버에서 작동합니다. Gmail은 2단계 인증을 켠 앱 비밀번호가 필요하고, Microsoft 365 로그인에는 테넌트 관리자 동의가 필요하며, 개인 Outlook.com은 확인된 게시자(verified publisher)여야 합니다(현재 대기 중). Proton은 Bridge가 필요합니다. 사용자 지정 IMAP 이동에는 UIDPLUS 또는 MOVE가 필요합니다. 메일 서비스나 테넌트 정책이 액세스를 차단할 수 있으며, 이 도구는 그러한 정책을 우회하지 않습니다.

문제가 생기면 어떻게 되나요?

멈추고 오류를 확인하세요. 스킬, CLI, 앱은 적용 전에 계획을 다시 확인하고 각 실행을 기록합니다. 표시된 undo 명령으로 해당 실행의 이동을 복원하세요. 메시지를 찾을 수 없게 되면 수동 복구를 위해 저널이 남아 있습니다. 구독 취소 요청은 되돌릴 수 없습니다.

정말 무료인가요?

네. MIT 라이선스이며, 유료 요금제도, CleanYourMail 계정도, 텔레메트리도 없습니다. 컴퓨터, Python 설치, 메일 서비스 액세스는 직접 준비하셔야 합니다.
